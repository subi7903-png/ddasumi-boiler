# 따수미보일러 랜딩페이지

Vercel / GitHub Pages 등에 바로 배포할 수 있는 정적 HTML 사이트입니다.

## 파일 구조

- `index.html` : 메인 랜딩페이지
- `vercel.json` : Vercel 정적 배포용 기본 설정
- `.gitignore` : 기본 Git 제외 파일

## GitHub → Vercel 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일들을 저장소 최상위에 업로드합니다.
3. Vercel에서 `Add New Project` → GitHub 저장소 선택
4. Framework Preset은 `Other` 또는 자동 감지
5. 별도 Build Command / Output Directory 설정 없이 Deploy
6. 배포 후 `https://프로젝트명.vercel.app` 형태의 URL이 생성됩니다.
